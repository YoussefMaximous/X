# loss-lens

Runs an MT4 expert advisor over a year of real ticks, finds every defect in how it traded, shows the proof for each, ranks them by cost, and jumps to each one on the MT4 chart.

## Teams (.teams/)
This project is run by a Lead (plans, reviews) and a Builder (implements).

If you are the Builder: at the start of every session and after any context compaction, re-read `.teams/teams/builder/CHARTER.md` and `.teams/teams/builder/HANDOFF.md`, follow the "Standing rules" in `.teams/ROSTER.md`, and work only from your brief in the highest-numbered file in `.teams/increments/`.

Do not edit this file or anything under `.teams/` outside `.teams/teams/builder/`.
